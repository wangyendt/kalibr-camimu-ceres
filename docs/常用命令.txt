# Kalibr Cam-IMU Ceres 常用命令

说明：以下命令都保持为单行，方便直接复制执行。默认从 `kalibr-camimu-ceres` 仓库根目录执行。

======================================================================
构建与测试
======================================================================

说明：Release 构建 Ceres cam-IMU。
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

说明：编译所有二进制。
cmake --build build -j

说明：运行轻量数值检查。
ctest --test-dir build --output-on-failure

======================================================================
帮助入口
======================================================================

说明：查看主标定器参数。
build/calibrate_cam_imu --help

说明：查看数据检查工具参数。
build/check_dataset --help

说明：查看 Kalibr/Ceres result 对比工具参数。
build/compare_kalibr_result --help

说明：查看输入转换脚本参数。
python3 tools/prepare_ceres_inputs.py --help

说明：查看 Kalibr Docker 基线脚本参数。
python3 tools/run_kalibr_docker.py --help

======================================================================
Kalibr Docker 镜像
======================================================================

说明：从 DockerHub 拉取 Kalibr Docker 镜像；本项目脚本会在本地缺少默认镜像时自动执行等价拉取。
docker pull wang121ye/kalibr-camera-calibration:20.04

说明：查看本机是否已有本地 Kalibr 镜像；有 `kalibr-camera-calibration:20.04` 时脚本优先使用本地镜像。
docker image inspect kalibr-camera-calibration:20.04

======================================================================
关联 cpp_tools 稀疏子模块
======================================================================

说明：初始化或修正 cpp_tools 稀疏子模块，只保留 apriltag_detection 和 camera_models。
tools/update_cpp_tools_sparse_submodule.sh

说明：构建 native EuRoC 导出所需的 cpp_tools pybind 模块；默认使用官方 Kalibr/cpp_tools upstream 的 apriltag gradient step=1。
tools/build_cpp_tools_pybinds.sh

说明：复现实验早期旧 Kalibr fork 的 apriltag gradient step=3；只用于历史对比，不作为当前默认口径。
KALIBR_APRILTAG_COMPAT=1 tools/build_cpp_tools_pybinds.sh

======================================================================
kalibr-camimu-ceres Docker 镜像（本项目 Ceres solver）
======================================================================

说明：默认构建（amd64）；Dockerfile 默认 BASE_IMAGE=ubuntu:20.04、BASE_IMAGE_PLATFORM=linux/amd64，自带全部构建依赖并用清华 pip 源装 pywayne，再用 gettool ceres -v 2.2.0 从源码编译 Ceres，不再依赖 Kalibr/ROS 基础镜像。
docker build -f docker/Dockerfile -t kalibr-camimu-ceres:amd64 .

说明：显式构建 amd64 镜像并加载到本地，与默认构建等价，便于在 arm 机器上做对照。
docker buildx build --platform linux/amd64 --build-arg BASE_IMAGE_PLATFORM=linux/amd64 --build-arg BUILD_JOBS=8 -f docker/Dockerfile -t kalibr-camimu-ceres:amd64 --load .

说明：本地构建 arm64 镜像（Apple Silicon 原生）；除 --platform 外还要把 BASE_IMAGE_PLATFORM 覆盖为 linux/arm64，否则 FROM 仍按默认拉 amd64 基础镜像。
docker buildx build --platform linux/arm64 --build-arg BASE_IMAGE_PLATFORM=linux/arm64 --build-arg BUILD_JOBS=8 -f docker/Dockerfile -t kalibr-camimu-ceres:arm64 --load .

说明：容器内查看主标定器参数，确认镜像可用。
docker run --rm kalibr-camimu-ceres:arm64 calibrate_cam_imu --help

说明：容器内运行 Ceres 完全独立标定；把生产数据目录挂到 /data、输出目录挂到 /out，命令里的路径全部改成容器内路径。
docker run --rm -v /Users/wayne/Documents/work/code/project/ffalcon/production_calibration/data:/data -v /private/tmp:/out kalibr-camimu-ceres:arm64 calibrate_cam_imu --corner-defaults --cam /data/2025_03_14_00_10_18/cam_imu/cam0-camchain-640x400.yaml --imu /data/2025_03_14_00_10_18/cam_imu/imu.yaml --target /data/2025_03_14_00_10_18/cam_imu/aprilgrid.yaml --imu-data /data/2025_03_14_00_10_18/cam_imu/data1.csv --corners /data/2025_03_14_00_10_18/cam_imu/cam0_640x400_corners.csv --corner-poses /data/2025_03_14_00_10_18/cam_imu/cam0_640x400_corner_poses.csv --estimate-time-shift-prior --estimate-orientation-gravity-prior --pose-fit-motion-lambda 0.0001 --pose-fit-boundary-anchors --time-shift-prior-sigma 0.0001 --pose-motion-prior --pose-motion-translation-variance 10 --pose-motion-rotation-variance 1 --max-iterations 150 --solver-max-trust-region-radius 10000000 --output-result /out/ceres_2025_03_14_00_10_18_independent.yaml
