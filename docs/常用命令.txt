# Kalibr Cam-IMU Ceres 常用命令

说明：以下命令都保持为单行，方便直接复制执行。默认从 `kalibr-camimu-ceres` 仓库根目录执行。

======================================================================
构建与测试
======================================================================

说明：Release 构建 Ceres cam-IMU。
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

说明：编译所有二进制。
cmake --build build -j

说明：运行轻量数值检查。
ctest --test-dir build --output-on-failure

======================================================================
帮助入口
======================================================================

说明：查看主标定器参数。
build/calibrate_cam_imu --help

说明：查看数据检查工具参数。
build/check_dataset --help

说明：查看 Kalibr/Ceres result 对比工具参数。
build/compare_kalibr_result --help

说明：查看输入转换脚本参数。
python3 tools/prepare_ceres_inputs.py --help

说明：查看 Kalibr Docker 基线脚本参数。
python3 tools/run_kalibr_docker.py --help

======================================================================
关联 Kalibr Docker 仓库
======================================================================

说明：在新工程下克隆当前 Kalibr Docker 包装仓库；已有 `external/kalibr-docker` 时不要重复执行。
git clone ../kalibr external/kalibr-docker

说明：用当前 Kalibr Docker 包装仓库构建基线镜像。
docker build -f external/kalibr-docker/docker/camera-calibration/Dockerfile -t kalibr-camera-calibration:20.04 external/kalibr-docker
