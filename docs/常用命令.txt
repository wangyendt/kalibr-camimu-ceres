# Kalibr Cam-IMU Ceres 常用命令

说明：以下命令都保持为单行，方便直接复制执行。默认从 `kalibr-camimu-ceres` 仓库根目录执行。

======================================================================
构建与测试
======================================================================

说明：Release 构建 Ceres cam-IMU。
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

说明：编译所有二进制。
cmake --build build -j

说明：运行轻量数值检查。
ctest --test-dir build --output-on-failure

======================================================================
帮助入口
======================================================================

说明：查看主标定器参数。
build/calibrate_cam_imu --help

说明：查看数据检查工具参数。
build/check_dataset --help

说明：查看 Kalibr/Ceres result 对比工具参数。
build/compare_kalibr_result --help

说明：查看输入转换脚本参数。
python3 tools/prepare_ceres_inputs.py --help

说明：查看 Kalibr Docker 基线脚本参数。
python3 tools/run_kalibr_docker.py --help

======================================================================
关联 Kalibr Docker 仓库
======================================================================

说明：在新工程下克隆当前 Kalibr Docker 包装仓库；已有 `external/kalibr-docker` 时不要重复执行。
git clone ../kalibr external/kalibr-docker

说明：用当前 Kalibr Docker 包装仓库构建基线镜像。
docker build -f external/kalibr-docker/docker/camera-calibration/Dockerfile -t kalibr-camera-calibration:20.04 external/kalibr-docker

======================================================================
Ceres 通用标定模板
======================================================================

说明：Ceres 完全独立标定模板；不传 Kalibr result，不读取 Kalibr 变量或结果。
build/calibrate_cam_imu --corner-defaults --cam /ABS/camchain.yaml --imu /ABS/imu.yaml --target /ABS/aprilgrid.yaml --imu-data /ABS/imu.csv --corners /ABS/cam0_corners.csv --corner-poses /ABS/cam0_corner_poses.csv --estimate-time-shift-prior --estimate-orientation-gravity-prior --pose-fit-motion-lambda 0.0001 --pose-fit-boundary-anchors --time-shift-prior-sigma 0.0001 --pose-motion-prior --pose-motion-translation-variance 10 --pose-motion-rotation-variance 1 --max-iterations 150 --solver-max-trust-region-radius 10000000 --output-result /private/tmp/ceres_independent.yaml

说明：Ceres 热启动诊断模板；只用于实验对比，显式读取 Kalibr result 作为初值。
build/calibrate_cam_imu --corner-defaults --cam /ABS/camchain.yaml --imu /ABS/imu.yaml --target /ABS/aprilgrid.yaml --imu-data /ABS/imu.csv --corners /ABS/cam0_corners.csv --corner-poses /ABS/cam0_corner_poses.csv --kalibr-result /ABS/results-imucam.txt --init-from-kalibr --pose-fit-motion-lambda 0.0001 --pose-fit-boundary-anchors --time-shift-prior-sigma 0.0001 --pose-motion-prior --pose-motion-translation-variance 10 --pose-motion-rotation-variance 1 --max-iterations 150 --solver-max-trust-region-radius 10000000 --output-result /private/tmp/ceres_hotstart.yaml

说明：Ceres 结果与 Kalibr result 离线对比；这是评测命令，不参与标定求解。
build/compare_kalibr_result --kalibr-result /ABS/results-imucam.txt --ceres-result /private/tmp/ceres_independent.yaml

说明：pkl 输入一键转换并运行 Ceres 单阶段标定。
python3 tools/prepare_ceres_inputs.py --source-type pkl --corner-pkl /ABS/corners.pkl --cams /ABS/camchain.yaml --imu /ABS/imu.yaml --imu-data /ABS/imu.csv --target /ABS/aprilgrid.yaml --out-dir /ABS/ceres_inputs --run-calibration -- --corner-defaults --estimate-time-shift-prior --estimate-orientation-gravity-prior

说明：bag 输入一键转换并运行 TUM parity 二阶段。
python3 tools/prepare_ceres_inputs.py --source-type bag --bag /ABS/data.bag --cams /ABS/camchain.yaml --imu /ABS/imu.yaml --target /ABS/aprilgrid.yaml --out-dir /ABS/ceres_inputs --run-two-stage
